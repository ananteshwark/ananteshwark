# Pinned dependency closure of requirements.txt. This is what deploy.sh and CI
# install.
#
# requirements.txt is the human-edited input and states only floors (>=). That
# is not a description of anything that has been tested: rebuilding from it
# resolves a different set every time, which is how a container rebuild during
# development produced an environment missing psycopg2, the AI providers and
# OCR — none of which the floors would have caught.
#
# Regenerate in a CLEAN virtualenv, never with a bare `pip freeze` in a
# development container. freeze reports everything importable, including the
# distribution's own OS packages: the first version of this file carried
# python-apt, PyGObject, dbus-python and conan, and CI could not install it at
# all because pycairo wanted system cairo headers that no app dependency needs.
#
#   python -m venv /tmp/lockenv
#   /tmp/lockenv/bin/pip install -r requirements.txt
#   /tmp/lockenv/bin/pip freeze > requirements.lock.txt
#
# Then run the suite against those versions before committing the result.
#
